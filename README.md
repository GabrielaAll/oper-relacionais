# ⚖️ Lista de Exercícios: Operadores Relacionais em Java

Repositório dedicado à resolução de exercícios práticos em **Java** focados no uso e entendimento de **operadores relacionais** e lógica booleana, desenvolvidos durante os estudos de programação.

---

## 📋 Sobre os Exercícios

O projeto aborda a comparação de valores numéricos e a manipulação de expressões lógicas, retornando sempre valores booleanos (`true` ou `false`):

### 👩‍🎓 Questão 1: Comparação de Notas entre Alunas
Criação de variáveis representando notas de duas alunas (`a` e `b`), testando e exibindo os resultados para três cenários diferentes:
- **Cenário 1:** $a = 10$, $b = 3$
- **Cenário 2:** $a = 3$, $b = 10$
- **Cenário 3:** $a = 5$, $b = 5$
*Verificando se são iguais, diferentes, se a primeira é maior e se a primeira é menor.*

### 🔍 Questão 2: Igualdade Simples
- Exibição na tela do resultado da comparação de igualdade (`a == b`) utilizando os valores $a = 10$ e $b = 3$.

### ⚡ Questão 3: Diferença
- Exibição na tela do resultado da comparação de diferença (`a != b`) utilizando os valores $a = 10$ e $b = 3$.

### 🌧️ Questão 4: Lógica Booleana e Negação
- Manipulação da variável booleana `chovendo = true` e retorno do resultado utilizando o operador de negação lógico (`!chovendo`).
